# Historical OMEx reference scripts

These are frozen source-audit copies, not the corrected workflow. Their bodies retain historical scales, paths and data assumptions and must not be used to regenerate corrected figures. Their locations and filename prefixes changed for repository organization; RELOCATION.csv in the campaign data directory records their original paths and byte hashes. The active entry points are the `[OMEx]_*.py` scripts directly in scripts/. New plot generation uses the shared corrected workflow, not these historical gnuplot/Python routines.
